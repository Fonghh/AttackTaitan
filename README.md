# AttackTaitan — 立體機動高速斬擊（原型）

受立體機動戰鬥啟發的 3D 動作遊戲原型：用左右雙鋼索在高樓間擺盪、累積速度，繞到巨人背後高速斬擊後頸弱點。
角色、巨人、城市、貼圖與音效全部由程式生成，沒有使用任何外部素材。

技術：Three.js 0.186 + Vite 8，純 JavaScript（ES Modules）。

**線上試玩：https://attacktaitan.alegu.workers.dev**（推到 `main` 後 Cloudflare 自動部署）

## 安裝與執行

```bash
npm install
npm run dev        # 開發模式（--host，手機在同一網路可直接連）
npm run build      # 輸出靜態檔到 dist/
npm run preview    # 預覽打包結果
npm test           # 物理與斬擊判定的單元測試（Node 內建 test runner）
npm run smoke      # 先 build，再用 Playwright 實際啟動遊戲跑完整流程並截圖
```

## 操作

**鍵盤＋滑鼠**（按「開始遊戲」後滑鼠會鎖定在畫面中）

| 按鍵 | 功能 |
| --- | --- |
| 滑鼠 | 視角／瞄準（準星左右各偏 10° 為左右鋼索的方向） |
| 左鍵或右鍵點一下 | 勾住（拉索：被拉過去；擺盪：鐘擺），再點一下＝放索往上衝（雙索模式：左右鍵各一條） |
| W A S D | 地面跑步、空中轉向；勾住時朝按的方向橫移、擺盪 |
| Space | 跳躍；勾住時捲收（朝勾點加速）；空中未勾索時噴氣上升 |
| Shift | 衝刺：勾住時按住＝快速捲收鋼索（氮氣式，越按越快），衝到勾點時鋼索放鬆、衝過頭往上飛；在地面＝低身滑鏟；空中沒勾住＝噴氣前進 |
| E 或 F | 斬擊；勾住時長按（0.22 秒）＝兵長斬 |
| Q | 解除全部鋼索 |
| R | 重新開始 |
| Esc / P | 暫停 |
| H | 顯示／隱藏操作說明 |

**手機（直立）**

- 像射擊遊戲：左下半部拖曳＝搖桿移動角色（勾住時往左右推＝朝那個方向橫移、擺盪）。
- 「鋼索」鈕＝準心搖桿：按住拖曳時準心在畫面上移動，放開＝朝準心發射；勾住時拖曳放開＝直接換勾點。
  兩段速度：0～8px 不動、8～45px 慢速微調（準心最多到 30%）、45～75px 快速衝到邊緣、
  再往外推鏡頭開始轉，推越遠轉越快（最快約 200°/秒）。手指碰到螢幕邊緣＝推到底。
- 快速甩動轉身（預設關閉，暫停選單可開）：在「鋼索」鈕上 0.18 秒內往左／右甩超過 50px → 鏡頭轉 90°。
- 點一下「鋼索」：沒勾住＝朝畫面中央發射，勾住＝放索往上衝。
- 空中推左搖桿左右＝鏡頭跟著轉（推 20% 以上開始，推到底約 140°/秒；鉤住時也有效，轉動時暫停「鏡頭跟隨人物」）。
  和右邊準心搖桿推到邊緣的轉動會相加，不衝突。暫停選單「空中左搖桿轉鏡頭」可切換強／中／弱／關。
- 鉤住時（與放索後 0.8 秒）鏡頭自動轉向人物面朝的方向；空白處拖曳可手動轉視角。
- 「斬擊」鈕：點一下＝斬擊；勾住時長按＝兵長斬。「衝刺」鈕在地面按＝滑鏟。
- 右下角按鈕：最右下「衝刺」、它左邊「斬擊」，「鋼索」在兩者中間的上方（右邊留約 110px 拖曳空間）。
- 準心吸附：準心靠近建築轉角／屋頂邊緣時會吸過去，準心標記變成金色菱形＝放開就勾在那裡。
- 暫停選單：準心靈敏度（50%～200%，預設 130%）、快速甩動轉身開關、速度線（高／中／低／關，預設中）、速度倍率（10%～150%，預設 50%；低速時拉力保有下限，斬擊的速度條件也照倍率換算）、衝刺倍率（10%～200%，預設 60%＝42 m/s）、鋼索手感（拉索／擺盪）、單索／左右雙索、鉤住時鏡頭跟隨人物、鏡頭跟隨飛行方向。

## 玩法重點

- **鋼索手感（暫停選單切換）**：
  - **拉索（預設）**：準星指哪勾哪，勾住後被拉向勾點（約 50 m/s，可用暫停選單的速度倍率調整），方向鍵／搖桿可以大幅側向橫移。
    到達或衝過勾點後停止拉動、鋼索不會斷，變成繞勾點擺盪；再按一下放索時向上速度加成往上衝。
    撞到牆的水平速度會先記住，翻過牆頂後還回來，繼續往前飛。
  - **擺盪**：鐘擺式擺盪，搭配擺盪輔助瞄準，往上甩時放開。
- 擺盪輔助瞄準：準星打中的點不夠高、正對著你的牆、或擺盪最低點會擦地時，會自動在準星附近
  （左右 21°、往上 28°）挑更適合擺盪的勾點，通常是街道兩側建築的側面或轉角。準星變紅＝附近沒有勾點。
- **勾住時的搖桿（拉索模式）**：前＝沿著繩子朝勾點捲進（含上下，不受鏡頭方向影響；推到底時重力降到 0，接近勾點時自動減速並停在勾點上，
  方便爬牆到頂再放索翻上去）、左右＝垂直於繩子繞著勾點橫移、後＝暫停收繩與拉動、維持距離。
  衝刺時重力只剩 15%；衝刺時同時往前推＝直衝目標（不放大擺盪），不推＝擺盪式衝刺。
- **自動收繩（拉索模式）**：勾住後繩子每秒固定收 8m（不管面朝哪裡），收到「繞圈半徑」為止：建築 8m，巨人 8m × 1.25 × 體型。
  不推搖桿＝被拉過去停在半徑上；往側邊推＝一邊收一邊繞（螺旋往內），最後繞小圈；往遠離勾點推＝暫停收繩、維持距離；往勾點推＝更靠近。
  建築仍在 6m 停止拉動（方便翻上屋頂）。暫停選單可調「自動收繩」（0～20 m/秒，0＝關）與「繞圈半徑」（4～20m）。
- **衝刺後的鬆繩**：衝到勾點後繩子放鬆（往上衝不會被扯住），飛過最遠點開始往下掉時才自動跟著收（最多比距離長 4m），之後恢復自動收繩，不會再出現 59m 的長繩大擺盪。
- **衝刺像氮氣加速**：剛按下只有約 25% 力道，按住 1.4 秒內逐漸疊到全力（收繩速度、拉力、角動量加速與最高速度都跟著漸增）。
  放開衝刺後速度不會被砍掉：最高速度上限從當下速度每秒只降 7 m/s，速度線與鏡頭拉近也慢慢退；短暫放開再按會接著之前的力道。
- **衝刺（擺盪式快速收繩＋往上直衝）**：勾住後按住衝刺，繩子快速收短（全力約 33 m/s），原本的擺盪不會被壓掉，
  而且繩子越短轉得越快（角動量守恆），保留六成重力產生甩動弧線；按下瞬間沿搖桿／擺盪方向補一下推力。衝到勾點時鋼索放鬆（不斷）並給向上加成，
  帶著速度衝過勾點往上飛。掉回來時放鬆的鋼索會在更長距離接住你；再按一次衝刺會重新拉緊。
- 勾住時撞牆，撞擊速度會轉成沿牆往上衝；此時放索可以翻上屋頂。
- **斬擊打擊感**：命中弱點時先「頓點」停格（0.11 秒，完美斬擊 0.18 秒），再從 25% 慢動作恢復；鏡頭往前推、猛震，
  命中點爆光、X 形交叉刀光線、沿刀路噴血。衝刺斬與鋼索衝刺時畫面四周出現放射狀速度線，衝刺斬會拖出殘光。
- 手機鉤住時：點一下（或 0.22 秒內、移動不到 40px 的短拖曳）＝放索；要刻意拖遠、拖久才會換勾點。
- 往上甩的時候放開鋼索：向上速度額外 +15%，接近頂點時有約 0.4 秒的減重滯空，可以看準下一棟樓。
- 落地速度夠快時會慣性滑行，滑行中可以直接再發射鋼索或起跳。
- 斬擊條件（畫面中央會顯示）：距後頸 ≤ 7m、速度 ≥ 20 m/s、從後方或側面接近。
  條件差一點時按斬擊會「衝刺斬」自動吸向弱點（耗氣體）。傷害隨速度增加，約 45 m/s 以上為完美斬擊。
- **5 隻巨人**（20～32m）：廣場 1 隻，大樓間街道上 4 隻（東街有 2 隻相距 50m）。巨人只在自己的地盤活動、不會穿進大樓，
  玩家靠近（95m 內）才會追擊與攻擊。全部討伐才算勝利。
- 巨人攻擊：右手揮擊（手掌發紅＝預備）；左手抓人（手掌發橘＝預備），被抓住要連打「斬擊」5 次掙脫，否則被捏扣 45 血。
- **部位斬擊**：砍眼睛＝暈眩 5 秒（不能轉身、攻擊）；砍腳踝＝跪下 4.5 秒（後頸變低，趁機砍）。
- **迴旋斬**：鋼索勾在巨人身上時按斬擊，整個人旋轉出招，範圍較大、傷害 ×1.15。
  在地面（或低空）靠近巨人腳踝時按斬擊也會迴旋斬砍腳（不需要速度）。
- **兵長斬**：鋼索勾住時長按斬擊 → 空中短拍（約 0.3 秒，速度收住、微微浮起、全身紅光蓄力）→ 沿鋼索直衝勾點：雙手往兩側張開、刀與手臂連成一直線，以身體自己的軸心（沿用出招當下的身體角度，和鋼索垂直或傾斜）高速迴旋，全身發紅光＋雙層光暈、粉紅殘光。
  抵達時勾在哪就砍哪：後頸（傷害 ×1.3，不看角度）、眼睛（暈眩）、腳踝（跪下並滑到背後）、其他部位（表皮傷害）；勾在建築上就是迴旋衝過去。
  命中後鋼索自動解除並往上彈出。目前沒有次數或冷卻限制。
- **地面滑鏟（氮氣式）**：站在地上（沒勾住）按住衝刺 → 壓低身體沿搖桿方向滑鏟，起步約 14 m/s，按越久加速越強（最高約 42 m/s × 速度倍率換算，下限 70%）。
  按住期間（與放開後 0.35 秒）可穿過巨人，經過腳踝會自動迴旋砍腳；放開後照一般滑行慢慢減速。
- **砍腳後滑到背後**：砍中腳踝時，勾在該巨人身上的鋼索收回，角色帶著慣性從腳邊滑過（可穿過巨人身體 0.8 秒），一路滑到巨人背後。
- 巨人死亡：勾在它身上的鋼索自動解除；屍體不能再勾、沒有碰撞，冒蒸氣 3 秒後淡出消失。最後一擊有側面擊殺特寫。
- 瞄準時準星附近（電腦 5°、手機 7°）有巨人且沒被建築擋住 → 優先勾巨人。
- 鋼索辨識：鋼索加粗並有光暈（左藍右橘）；勾住的位置有發光圓環（被建築擋住也看得到）；準心旁短暫顯示「勾住」或「沒勾到」。
- 速度線只在角色外圍 4～11m 生成，角色、鋼索與畫面中央保持乾淨。
- 鏡頭：靠近巨人時壓低往上仰；衝刺時拉近角色。命中與衝刺斬時畫面有紅藍色差；刀身拖出紫／藍殘光。不顯示傷害數字。
- 左右擺盪倍率（暫停選單 50%～300%，預設 200%＝52 m/s²）：勾住時方向鍵／搖桿的側向操控力。

## 鏡頭與演出

- **鎖定鏡頭**（預設開）：鋼索勾在巨人身上時，鏡頭自動對準那隻巨人（後頸往下一點），角色在畫面下方前景。
  鎖定時左搖桿左右＝繞著巨人轉、前後＝靠近／拉開；左搖桿轉鏡頭與陀螺儀暫停。手動轉鏡頭（準心推到邊緣、滑鼠）0.7 秒內不搶鏡頭，
  持續轉超過 0.5 秒＝解除鎖定，直到下次勾住。放開鋼索或巨人死亡就解除。
- 鎖定時角色身體朝向巨人（背對鏡頭繞圈，出刀一直朝著目標）；靠近巨人時自動甩出連續的淡刀光。
- **鏡頭側傾**（18°／9°／0°，預設 9°）：依鏡頭轉動速度與側向加速度往彎內傾。
- **近距離廣角鏡頭**（預設開）：鏡頭距離 6.5m → 3.3m（角色在畫面上更大），速度帶來的 FOV 加大（最多 +34°）。貼地高速飛行時鏡頭壓低；命中瞬間鏡頭往命中點推近。
- **瓦斯雲軌跡**：勾住飛行、噴氣、衝刺時身後拖出白色瓦斯雲（停留 1～2 秒、慢慢擴散，衝刺最濃）；離鏡頭太近的粒子會淡掉，不糊住畫面。
- **刀刃火花**：高速貼地（2m 內）或貼牆（1.6m 內）飛行、滑行時刀尖刮出火花，有刮擦聲；滑行時右手的刀拖在地上。
- **鋼索**：放鬆時依多出來的長度往下垂（最多 14m），重新繃緊時「啪」一下變亮變粗、抖動；鉤爪飛行時留下白色光跡。
- **風壓漩渦**：高速繞圈、衝刺、兵長斬、迴旋斬時身邊出現旋轉的透明風紋。
- **角色姿勢**：跟著側向加速度往彎內傾（繞圈時整個人斜躺）；飛越快雙刀越往後張開；衝刺時縮身前衝。
- **巨人受擊**：整隻閃紅；命中處留下傷口（跟著身體動、冒蒸氣，約 15 秒淡掉）。
- **擊殺**：全螢幕金色放射光＋低沉爆裂聲；完美斬擊有短的金光。擊殺特寫的鏡頭對準角色與後頸的中點，兩者都在畫面裡。
- **衝擊幀**：斬中後頸、兵長斬、擊殺的瞬間，畫面變成白底黑剪影約 0.12 秒（擊殺 0.18 秒）。
- **刀光**：新月形、比之前大約 1.7 倍。
- **翻轉衝刺（二段衝刺）**：空中 0.3 秒內連點兩下衝刺 → 先捲身翻一圈（0.6 秒頓點，空中幾乎停住），再往搖桿方向（沒推就往鏡頭前方）爆衝 1.4 秒（速度不變）；
  勾住時沿繩子爆衝到勾點會自動脫勾，帶著速度繼續往上衝。
  之後保留慣性（最高速度上限每秒慢慢降）。勾住（鋼索繃緊）時以繩子為準：搖桿前＝沿繩子朝勾點、左右＝繞著勾點、後＝遠離；沒推搖桿＝沿繩子衝。耗氣 15，冷卻 0.8 秒。衝過頭的話調低 `dash.flip.speed`。
- **地面奔跑（迎風跑）**：上身往前彎到接近水平，頭在前上、腰在中、膝蓋與腳跟拖在後下方；雙刀與身體垂直往兩側伸出。
  轉彎時重心往彎內傾，內側刀尖壓到地面刮出火花。
- 暫停選單「鉤索射程」：60～150m（預設 85m）。

## 手機瀏覽器注意

iOS Safari 會忽略 `user-scalable=no`，連點按鈕會觸發「點兩下放大」而且重新整理後還保留縮放。`src/main.js` 會攔掉遊戲區的快速連點與雙指縮放，
並在偵測到畫面被放大時重設 viewport 回到 1 倍（選單面板不攔，按鈕照常可點）。

## 巨人與角色外觀

- **巨人**：每隻外觀依名字與位置固定產生（`spawn.look` 可指定）：體型（標準／瘦長／壯碩大肚）、膚色（7 種）、
  表情（咧嘴笑／面無表情／怒吼）、頭髮（短髮／長髮／光頭／亂髮，6 種髮色），加上三角肌、二頭肌、胸肌、六塊腹肌、鎖骨、
  大腿與小腿肌肉、膝蓋骨、手指腳趾、耳朵鼻子下巴。同一個關節、同一種材質的零件合併成一個網格（每隻約 35 個網格），手機比較順。
  碰撞球依體型調整。
- **奇行種**（`kind: 'abnormal'`，城區「西街奇行種」、森林「東林奇行種」）：瘦長大頭大眼咧嘴笑；方向亂飄地狂奔（9 m/s × 體型）；
  距離 7～34m（× 體型）時蹲低 0.65 秒（畫面警告）後預判玩家位置，以拋物線飛撲過去（落點不超出牠的地盤；路線會避開比跳躍高度高的建築，在撞到前落下，矮房子跳得過），身體任何部位撞到或落地時在落點附近＝ 30 傷害並擊飛；
  落地後硬直 1.4 秒（趁機砍），冷卻 4 秒。很近時改用一般揮擊。
- **主角**：立體機動裝置（腰後兩側氣罐與閥門、刀箱、鋼索盒捲筒與噴嘴）、胸前 X 字皮帶、腰帶、大腿綁帶；
  刀有握把、扳機、護手與刀刃反光條，金屬用環境反射（會反光）；披風是彈簧擺（被速度吹向後方、側移吹向側邊、下墜時往上飄，轉彎會甩動）。
- **瓦斯雲帶**：空中噴氣或勾著飛時，腰後兩側拉出兩條柔和的雲狀帶子（一團一團、邊緣柔和），停留 3.5 秒、慢慢擴散變淡，和細長發亮的鋼索區分開（`trailLines`）。

## 發佈到 Cloudflare

專案已備好 Cloudflare Workers 靜態網站設定（`wrangler.jsonc` 指定發佈 `dist`、`.node-version` 指定 Node 22、`public/_headers` 設定快取），用 Git 連動部署，不需要 API 金鑰：

1. Cloudflare 後台 → Workers & Pages → Create → 匯入 Git 儲存庫 `fonghh/attacktaitan`。
2. Build command：`npm run build`；Deploy command：`npx wrangler deploy`（預設值）。
3. 部署的分支需要有這些設定檔（目前在 `feature/grapple-prototype`，合併到 `main` 後 `main` 也可以）。
4. 之後每次 push 都會自動重新部署。
