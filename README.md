# AttackTaitan — 立體機動高速斬擊（原型）

受立體機動戰鬥啟發的 3D 動作遊戲原型：用左右雙鋼索在高樓間擺盪、累積速度，繞到巨人背後高速斬擊後頸弱點。
角色、巨人、城市、貼圖與音效全部由程式生成，沒有使用任何外部素材。

技術：Three.js 0.186 + Vite 8，純 JavaScript（ES Modules）。

## 安裝與執行

```bash
npm install
npm run dev        # 開發模式（--host，手機在同一網路可直接連）
npm run build      # 輸出靜態檔到 dist/
npm run preview    # 預覽打包結果
npm test           # 物理與斬擊判定的單元測試（Node 內建 test runner）
npm run smoke      # 先 build，再用 Playwright 實際啟動遊戲跑完整流程並截圖
```

## 操作

**鍵盤＋滑鼠**（按「開始遊戲」後滑鼠會鎖定在畫面中）

| 按鍵 | 功能 |
| --- | --- |
| 滑鼠 | 視角／瞄準（準星左右各偏 10° 為左右鋼索的方向） |
| 左鍵或右鍵點一下 | 勾住（拉索：被拉過去；擺盪：鐘擺），再點一下＝放索往上衝（雙索模式：左右鍵各一條） |
| W A S D | 地面跑步、空中轉向；勾住時朝按的方向橫移、擺盪 |
| Space | 跳躍；勾住時捲收（朝勾點加速）；空中未勾索時噴氣上升 |
| Shift | 加速（消耗氣體）；勾住時沿擺盪方向加速 |
| E 或 F | 斬擊 |
| Q | 解除全部鋼索 |
| R | 重新開始 |
| Esc / P | 暫停 |
| H | 顯示／隱藏操作說明 |

**手機（直立）**

- 像射擊遊戲：左下半部拖曳＝搖桿移動角色（勾住時往左右推＝朝那個方向橫移、擺盪）。
- 「鋼索」鈕＝準心搖桿：按住拖曳時準心在畫面上移動（鏡頭不轉），放開＝朝準心發射；勾住時拖曳放開＝直接換勾點。
  準心推到畫面邊緣時鏡頭會慢慢跟著轉。
- 點一下「鋼索」：沒勾住＝朝畫面中央發射，勾住＝放索往上衝。
- 鉤住時（與放索後 0.8 秒）鏡頭自動轉向人物面朝的方向；空白處拖曳可手動轉視角。
- 右上「加速」、右下「斬擊」。
- 暫停選單：速度倍率（50%～150%）、鋼索手感（拉索／擺盪）、單索／左右雙索、鉤住時鏡頭跟隨人物、鏡頭跟隨飛行方向。

## 玩法重點

- **鋼索手感（暫停選單切換）**：
  - **拉索（預設）**：準星指哪勾哪，勾住後被拉向勾點（約 50 m/s，可用暫停選單的速度倍率調整），方向鍵／搖桿可以大幅側向橫移。
    到達或衝過勾點後停止拉動、鋼索不會斷，變成繞勾點擺盪；再按一下放索時向上速度加成往上衝。
    撞到牆的水平速度會先記住，翻過牆頂後還回來，繼續往前飛。
  - **擺盪**：鐘擺式擺盪，搭配擺盪輔助瞄準，往上甩時放開。
- 擺盪輔助瞄準：準星打中的點不夠高、正對著你的牆、或擺盪最低點會擦地時，會自動在準星附近
  （左右 21°、往上 28°）挑更適合擺盪的勾點，通常是街道兩側建築的側面或轉角。準星變紅＝附近沒有勾點。
- 勾住時撞牆，撞擊速度會轉成沿牆往上衝；此時放索可以翻上屋頂。
- 往上甩的時候放開鋼索：向上速度額外 +15%，接近頂點時有約 0.4 秒的減重滯空，可以看準下一棟樓。
- 落地速度夠快時會慣性滑行，滑行中可以直接再發射鋼索或起跳。
- 斬擊條件（畫面中央會顯示）：距後頸 ≤ 7m、速度 ≥ 20 m/s、從後方或側面接近。
  條件差一點時按斬擊會「衝刺斬」自動吸向弱點（耗氣體）。傷害隨速度增加，約 45 m/s 以上為完美斬擊。
- 巨人會追擊並揮手攻擊（手掌發紅＝預備動作），被打中會被擊飛並扣血。

## 程式結構

```
src/
  config.js                 所有手感參數（重力、繩索、加速、滑行、滯空、斬擊、攝影機…）
  main.js                   進入點
  core/game.js              遊戲主控：模組組裝、輸入事件、主迴圈、戰鬥流程、勝負
  physics/motion.js         球體 vs 方塊／球體碰撞、鋼索長度約束、子步數（純函式）
  physics/grapple.js        單條鋼索狀態機、鋼索瞄準與輔助瞄準
  player/playerController.js 玩家移動與立體機動物理（擺盪、捲收、加速、滑行、上甩、滯空）
  player/playerModel.js     程序化角色模型與姿勢動畫
  camera/cameraRig.js       第三人稱攝影機（依速度拉遠／FOV、防穿牆、手機自動跟隨）
  enemy/titan.js            巨人模型、AI 狀態機、後頸弱點、揮擊判定
  combat/strike.js          斬擊判定與傷害計算（純函式）
  input/input.js            鍵盤滑鼠＋觸控整合
  ui/hud.js                 HUD、預測標記、弱點提示、訊息
  ui/touchControls.js       手機虛擬搖桿與按鈕
  fx/effects.js             粒子、速度流線、鋼索、刀光
  audio/audio.js            WebAudio 合成音效
  world/city.js, textures.js 城市場景與程序化貼圖
tests/
  physics.test.js           單元測試
  smoke.mjs                 Playwright 煙霧測試
```
